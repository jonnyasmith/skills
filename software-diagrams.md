# Software Diagrams

Software diagrams are visual blueprints used to map out a system's structure, behavior, and underlying architecture. They translate complex technical concepts into clear visuals tailored for developers, system architects, and business stakeholders.

## Unified Modeling Language (UML) Diagrams
UML is the industry standard for modeling software systems, split into two main categories:
## Structural Diagrams

* Class Diagram: Shows system classes, attributes, methods, and the relationships between objects.
* Component Diagram: Illustrates how software pieces are modularized and wired together.
* Deployment Diagram: Maps out the physical hardware hosting the software artifacts.
* Object Diagram: Captures a real-time snapshot of instances in a system at a specific moment.
* Package Diagram: Groups related elements together to show dependencies between subsystems.

## Behavioral Diagrams

* Sequence Diagram: Tracks the chronological flow of messages exchanged between objects over time.
* Use Case Diagram: Defines high-level user interactions and system boundaries for stakeholders.
* Activity Diagram: Models operational workflows, conditional logic, and parallel processes step-by-step.
* State Machine Diagram: Details the various lifecycle states an object transitions through based on triggers.
* Communication Diagram: Highlights the structural organization of objects that exchange messages.

## Architecture & Data Design Diagrams
These diagrams focus on high-level system components, data storage, and external integrations.

* C4 Model Diagrams: Zooms into software architecture through four progressive levels: Context, Containers, Components, and Code.
* Entity-Relationship Diagram (ERD): Maps out database structures, showing tables, columns, primary keys, and data relationships.
* Data Flow Diagram (DFD): Tracks how data moves through a system, highlighting inputs, outputs, storage, and transformations.
* System Architecture Diagram: Displays cloud infrastructure layout, networks, and integrations using cloud-native icons (like AWS or Azure).

## Agile & User Experience Diagrams
These tools align technical development teams with product managers and end-user goals.

* User Story Map: Organizes user tasks into a visual matrix to prioritize feature releases.
* UI Flowchart (Wireframe Flow): Maps user navigation paths through different application screens and interfaces.
