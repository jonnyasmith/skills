# Web Verification

- Use the integrated browser to verify the real user flow: navigate, interact,
  and confirm visible state. Check browser errors and relevant network
  behaviour when they bear on the goal.
- Make the run reproducible: control fixtures, time, randomness, and cleanup.
- Use a visible browser result or independent consumer as the acceptance
  oracle; do not merely restate implementation assumptions.
- Add accessibility, performance, privacy, or security proof only when the
  changed surface makes that risk relevant.
